# 安装配置与检查（核心度 ★★）

## Purpose

将源码和固定版本运行资源组装成可运行的本地演示，提供角色导入与基础检查。仓库以直接运行 ES Modules 为主。

## Key Files

| 文件 | 作用 |
|---|---|
| `package.json`、`package-lock.json` | Node版本、固定依赖与四个脚本 |
| `tools/setup.ps1` | 下载、SHA、解压 CPU/CUDA 资源、写配置 |
| `assets/resources.json` | 固定下载 URL、目标位置、SHA |
| `tools/import_avatar.mjs` | VRM 大小/骨骼检查并复制到本地角色位置 |
| `tools/check.mjs` | ES模块语法、相对引用、部分运行资源校验 |
| `.gitignore` | node_modules、runtime、Temp、角色、GGUF 等本地文件 |
| `LICENSE`、`THIRD_PARTY_NOTICES.txt`、`licenses/` | 项目非商业条款与第三方资源声明 |

## Public Interface

| npm 脚本 | 实际命令 |
|---|---|
| start | `node service/start.mjs` |
| setup | `powershell -NoProfile -ExecutionPolicy Bypass -File tools/setup.ps1` |
| check | `node tools/check.mjs` |
| avatar | `node tools/import_avatar.mjs` |

## Internal Flow

```text
npm ci -> node_modules
setup.ps1 -> resources manifest -> .part download -> SHA -> destination
  -> extract runtime -> set device/gpu_layers -> remove downloaded archive
import_avatar -> size + VRM + required bones -> assets/avatar.vrm
check -> node --check + relative import access -> hashes + shape/registry
```

已有且 SHA 匹配的下载目标会跳过；已有 avatar 不被 setup 替换。CPU/CUDA 是二选一安装路径，CUDA 还下载对应 cudart。setup 会修改被跟踪的 `configs/qwen_intent.json`；学习时运行后应检查 Git 差异。

## Dependencies

安装使用 PowerShell Utility/Archive 和网络；程序依赖 Node、three、three-vrm、固定 llama.cpp 与 Qwen GGUF。[[本地服务]]、[[中文意图与进程]] 和 [[模型资源与运行时]] 使用其输出，具体命令见 [[上手指南]]。

## Configuration

语言配置在 `configs/qwen_intent.json`，控制配置在 `configs/v9_control.json`，来源审核在模型目录与 `configs/v15_review.json`。本版无需外部 API key；`local.settings.json` 被忽略，但当前启动链没有将其作为通用配置来源。

## Testing

在项目根执行 `node tools/check.mjs`。当前结果为123个模块、62个资源文件通过。没有独立 test/build/lint npm 脚本，也未发现 CI 工作流；不得虚构 `npm test` 或训练命令。完整运行还需安装、启动、真实中文推理与浏览器动作观测。

本次环境只有 node 可用，npm 不在 PATH，JS依赖、VRM、GGUF 与 llama-server 都未安装；没有进行下载或修改运行配置。执行边界记录在 [[来源与验证]]。
