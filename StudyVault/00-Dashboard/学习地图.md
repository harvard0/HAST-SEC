# HAST-SEC 学习地图

## Architecture Overview

HAST-SEC 是本地交互演示：**Node.js HTTP 服务 + 本地 llama.cpp 推理子进程 + 浏览器运动与 VRM 渲染**。服务端给出动作计划，浏览器选择已登记动作码，再执行固定频率约束求解。

| 技术 | 代码证据 | 学习入口 |
|---|---|---|
| Node.js ≥22、原生 ES Modules、原生 HTTP | `package.json`、`service/start.mjs` | [[本地服务]] |
| Three.js 0.180.0、three-vrm 3.5.5、浏览器 importmap | `package.json`、`web/v13_lab.html` | [[角色骨架与旋转]] |
| 本地 Qwen3.5-0.8B-Q8_0、llama.cpp | `configs/qwen_intent.json`、`service/qwen_process.mjs` | [[中文意图与进程]] |
| 小型选择网络、原型轨迹、历史先验、数值约束求解 | `models/`、`training/`、`motion/v9/` | [[模型资源与运行时]] |

→ [[系统架构]] · [[指令执行链路]] · [[数据与坐标契约]]

## Getting Started

在项目根目录执行 `npm ci`，再执行 `npm run setup`，最后 `npm start`，访问 `http://127.0.0.1:8769/language-lab`。完整 CPU/CUDA 二选一路径、环境说明和源码检查命令见 [[上手指南]]。
