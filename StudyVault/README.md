# HAST-SEC 代码学习库

从 [[学习地图]] 开始。先读 [[系统架构]] 与 [[指令执行链路]]，再沿模块进入源码，最后用 [[服务端练习]] 等折叠答案练习检查理解。

在 Obsidian 中将 **StudyVault** 文件夹作为仓库打开。笔记内双向链接指向本学习库；代码路径均相对 **HAST-SEC 项目根目录**，可在代码编辑器中定位。无需 Obsidian 插件。

本库依据提交 `f4d5c9aa32f9d04e249585e0b2e6d4c56572ca51` 的本地源码编写，整理完成日期为 2026-10-24。它解释当前公开运行版；源码中的版本名、模型元数据和 README 的能力声明，需要分别理解。证据范围见 [[来源与验证]]。

## 建议用法

1. 用 [[上手指南]] 完成环境准备；只读源码也可以开始学习。
2. 每读一个模块，先用自己的话画出输入、处理、输出，再展开对应练习的答案。
3. 在 [[易错点与复习]] 中记录自己的疑问；没有答题记录前，不预设薄弱项。
4. 修改代码后运行原项目检查；修改笔记后执行 `node StudyVault/_tools/validate.mjs`。
