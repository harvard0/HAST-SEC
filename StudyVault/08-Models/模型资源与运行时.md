# 模型资源与运行时（核心度 ★★★）

## Purpose

保存并加载连续身体原型、动作候选、选择器、时序与历史先验，为浏览器推理和求解提供固定数据。目录名 training 包含当前运行时依赖，也保留数学拟合辅助。

## Key Files

| 目录 / 文件 | 数据或作用 |
|---|---|
| `models/body/` | 身体网络权重、48原型、方向、审核和来源过滤 |
| `models/skills/` | 22个基础类、4份来源分片，共51个来源 |
| `models/control/` | 4个扩展类、base/idle/expert/wave 与 codes |
| `models/policy/` | 局部选择权重、32维文本条件、条目与历史指标 |
| `models/timing/` | 周期选择网络 |
| `models/history/` | 4阶历史模型、8份参数分片、统计区域分片 |
| `models/trajectories/` | 技能来源的 Float32 四元数轨迹 |
| `training/beat_runtime_v9.mjs` | 新片段上叠加位姿/速度残差衰减 |
| `training/beat_direction_runtime.mjs` | 方向积分与有限朝向速度 |
| `training/history_model_io.mjs` | 历史参数拼装和形状检查 |
| `training/v13/selector.mjs` | poseFeatures、softmax 前向，也含 fitSelector 辅助 |

## Public Interface

| 导出 | 用途 |
|---|---|
| `loadBeatModel(prefix)` | 加载身体资源、校验、排除来源、创建运行时 |
| `loadDirectionModel(options)` | 增加方向与噪声模型，接入 bodyFactory |
| `skillAssets(bootstrap)` | 返回 entries/sources/load，按需加载技能轨迹 |
| `weights(name,prefix)` | 校验通用选择网络权重 |
| `readHistoryModel(prefix,read)` | 读取索引/分片、检查维度、lags、rate |
| `poseFeatures`、`selectorForward` | 姿态差特征与选择网络前向 |

## Internal Flow

```text
server route aliases -> model metadata + binary
  -> SHA / shape / finite / bones / registry checks
  -> body + direction runtime -> continuous base
  -> skill classes + on-demand trajectories -> local tracks
  -> history parameters + regions -> solver priors
```

bodyFactory 在当前入口注入 `beatRuntimeV9(...,{policy})`。v9 接续保留新轨迹本身，以有限时长衰减旧/新接缝的位姿和速度残差；方向运行时在其外层调整整体朝向。

## 数据事实与历史指标

身体元数据为53骨骼、19面部通道、dim=178、80帧/原型、48原型、20Hz。历史模型 dim=181、lags=4、20Hz。基础22类和扩展4类合并为26类；运行装配检查 registry 和骨骼顺序一致。

`metrics.json`、`review.json` 和 kind 字段记录随仓库分发的模型历史信息。它们有助于了解来源，但不是本次模型重训、重新评分或完整强化学习能力的证据。README 明确未提供完整训练工具链和原始视频。

## Dependencies

运行时依赖 three、[[角色骨架与旋转]] 的旋转数学和普通数值函数。[[本地服务]] 映射资源；[[页面与对话]] 加载资源；[[动作策略与轨道]]、[[姿态约束与求解]]、[[面部表情]] 消费数据。

## Configuration

`configs/v15_review.json` 控制排除的待机来源；`models/body/source-filter.json` 过滤来源，`review.json` 关联原型码库 hash。改二进制时要检查元数据 SHA、形状、骨骼序与审批关联。仅改 hash 不能证明来源或动作质量合格。

## Testing

`node tools/check.mjs` 已通过62个文件的运行资源校验，包含51份轨迹；还检查部分 registry 一致性及类 JSON。浏览器加载会追加更多网络形状/来源约束。该命令不验证全部 JSON 业务语义，也不读取安装后语言资源作为真模型验收。
