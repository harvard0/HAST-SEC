# 本地服务（核心度 ★★★）

## Purpose

提供本机网页、模块与运行数据，将中文请求交给模型适配层；负责本地访问边界、资源采样和服务关闭。

## Key Files

| 文件 | 作用 |
|---|---|
| `service/start.mjs` | 根路径、PORT、信号关闭 |
| `service/public_server.mjs` | createServer、请求分派、静态文件边界、CSP |
| `service/public_routes.mjs` | 路由白名单与历史 URL 到当前资源的映射 |
| `service/public_api.mjs` | 技能库、API 输入检查、推理调用 |
| `service/public_resources.mjs` | 存储与 RSS 采样，短缓存 |
| `service/media.mjs` | 文件流与范围请求处理 |

## Public Interface

| 导出 | 契约 |
|---|---|
| `publicServer(root, port=8769)` | 返回 `{url, api, close}`，port 可为 0 交给系统分配 |
| `runtimeRoutes(root)` | 返回 URL → 项目文件 Map |
| `publicApi(root)` | 返回处理函数及 close/state 属性 |
| `resourceProbe(root, state)` | 返回异步采样函数 |

## Internal Flow

```text
request -> Host/Origin gate -> decode path -> reject invalid path
  -> publicApi (recognized API?)
  -> GET/HEAD only -> dynamic resources/profile/source-filter
  -> explicit route/vendor mapping -> realpath boundary -> streamMedia
```

仅绑定 `127.0.0.1`。Host 必须是当前端口的 `127.0.0.1` 或 `localhost`；若携带 Origin，须等于请求 Host 的 HTTP 同源地址。静态文件通过 route Map 或 vendor 映射选择，再检查 realpath 边界。

## 路由别名

| URL 前缀 | 磁盘目录 |
|---|---|
| `/baseline-v9-filtered-data/` | `models/body/` |
| `/feasible-history/` | `models/history/` |
| `/v15-data/` | `models/control/` |
| `/v14-data/` | `models/timing/` |
| `/v14-policy/` | `models/policy/` |
| `/v13-sources/{id}.bin` | 已登记的 `models/trajectories/{file}` |
| `/vendor/three/`、`/vendor/vrm/` | 对应 node_modules 路径 |

## Dependencies

使用 Node 标准库、[[中文意图与进程]]、[[模型资源与运行时]] 和 [[角色骨架与旋转]] 的动态 profile。被 `service/start.mjs` 启动，被 [[页面与对话]] 调用。

## Configuration

`PORT` 默认 8769；服务器 `requestTimeout=15000`、`headersTimeout=10000`。模型端口和设备归语言模块。它没有数据库连接串或外部 API 密钥。

## Testing

运行 `node tools/check.mjs` 检查语法与相对引用。运行服务后可用 `Invoke-RestMethod http://127.0.0.1:8769/v13-api/status` 验证 GET；POST 需要正确 Origin，示例见 [[HTTP接口]]。仓库无专门 HTTP 自动测试套件；本库创建时未运行完整服务/浏览器体验。
