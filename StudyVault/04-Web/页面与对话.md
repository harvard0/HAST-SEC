# 页面与对话（核心度 ★★★）

## Purpose

装配运行模块、接收用户事件、管理消息排队和主动对话，把计划接入身体与表情，并显示可观察的运行状态。

## Key Files

| 文件 | 作用 |
|---|---|
| `web/v13_lab.html`、`web/v15_start.mjs` | 页面容器、importmap、样式 |
| `web/v13_lab.mjs` | 初始化、play/pause/reset、求解循环、调试对象 |
| `web/v13_command.mjs` | send/proactive、context、queue、revision |
| `web/v13_latency.mjs` | 预热、30秒 keep interval、前端取消 |
| `web/v15_dialogue.mjs` | 回复表现、监听/交流状态、问候手势、主动聊天 |
| `web/dialogue_pages.mjs`、`web/dialogue_bubble.mjs` | 字素分页与每页 3.5秒自动显示 |
| `web/v15_dashboard.mjs`、`web/v15_controls.mjs` | 运动与求解指标 |
| `web/v15_resources.mjs` | 每约3秒取样资源数据 |

## Public Interface

`commandLoop(ctx)` 返回 session、send、proactive、cancel、state、reset；`dialogueController(ctx)` 暴露 bind/pending/receive/step/brief/state/reset。初始化完成后可用 `window.languageV13` 观察或操作运行，见 [[快速参考]]。

## Internal Flow

```text
initialization -> reset(paused)
user play -> requestAnimationFrame -> fixedClock.advance/display
user send -> queue or prepare/fetch -> apply plan -> dialogue.receive
page hidden / pause -> cancel RAF + command cancel + POST stop
reset -> pause + clear behavior/layers/view/dialogue/clock/history/context
```

### 异步消息与短历史

普通请求正在执行时最多排六条等待消息；主动对话被用户消息打断时，先取消客户端，再发送服务端 interrupt。revision/ticket 使过期响应失效，每个关键 await 后核对。context 保留最多四条、总长 ≤1200；reset 清空，页面刷新不从服务端恢复历史。

### 表现与主动聊天

回复 ≤40 个字素时前端强制 brief。剩余表现时间按气泡页数×3.5秒计算，并限制在 5–60秒；conversation 通知底座持续交流。gesture 非 none 时从技能库取左右问候技能，加载并进入轨道。

主动聊天需处于播放中、进入底座 chat 状态、没有等待回复或动作等条件；还有至少约20秒的调度间隔。它不是无条件定时聊天。

### 两种时钟

身体表现 `dialogue.step(dt)` 跟随求解时间；气泡翻页用 `setTimeout` 的墙钟。理解暂停显示时要分别定位计时器，不能假设所有 UI 都由求解时钟驱动。

## Dependencies

使用 DOM、requestAnimationFrame、fetch、crypto.randomUUID、Intl.Segmenter、ResizeObserver、WebGL 和可选浏览器语音。依赖 [[HTTP接口]]、[[动作策略与轨道]]、[[姿态约束与求解]]、[[角色骨架与旋转]]、[[面部表情]] 与 [[模型资源与运行时]]。

## Configuration

`?debug=1` 开启调试样式。输入 maxlength=300；图表10Hz采样、保留15秒，求解20Hz。前端临时调参作用于内存 config 并可重置/重建 solver，不写模型权重。

## Testing

运行 `node tools/check.mjs`，在完整安装后用浏览器观察初始化、连续发送、主动聊天中断、暂停/重置和页面隐藏。对气泡检查 emoji 字素、换行、长回复和窄屏。当前没有浏览器自动测试或渲染结果证据。
